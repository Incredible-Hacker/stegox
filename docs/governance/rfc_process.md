# RFC Process

StegoX uses a lightweight RFC (Request for Comments) process for
non-trivial changes.

## When to write an RFC

- Changes to the CLI grammar.
- Changes to the plugin protocol.
- Changes to the report schema.
- New core algorithms.
- Anything that affects the public API surface.

## RFC lifecycle

1. **Draft** — open a PR with the file under `rfcs/`.
2. **Discussion** — community and maintainers weigh in.
3. **Accepted** — merged into `rfcs/`.
4. **Implemented** — tracked via issues linked from the RFC.
